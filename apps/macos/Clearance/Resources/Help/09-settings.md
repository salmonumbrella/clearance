# Settings

Open the Settings dialog with **Clearance** > **Settings…** (⌘,). It holds preferences for opening files, appearance, and Dock visibility, plus a button to install the command-line tool.

## Default Open Mode

This sets the mode newly opened files start in — **View** or **Edit**. Choose **View** to land on the formatted page, or **Edit** to start in the Markdown text. You can always switch once a document is open; see [Viewing and Editing](03-viewing-and-editing.md).

## Theme

Pick the look of the rendered page:

- **Apple** — neutral tones with system-accent links.
- **Classic Blue** — the original indigo-heavy Clearance palette.

## Appearance

Choose **Light**, **Dark**, or **System** to follow whatever your Mac is set to.

## Dock Visibility

**Hide Dock icon when no document is open** is off by default. Turn it on to keep Clearance running without a Dock icon while its workspace is empty or all document windows are closed. Opening a local file or successfully loading a remote document brings the icon back. A minimized document or a document in a separate window keeps the icon visible.

When the icon is hidden, macOS also hides Clearance's app menu bar. Use **New…**, **Settings…**, or **Quit Clearance** in the empty workspace, or its **Open…** button to open a document. If the workspace is closed, open Clearance from Finder or open a file with Clearance to bring it back. Turn the setting off to show the Dock icon immediately.

## Command-Line Tool

The dialog also has a button to install the `clearance` command, which opens files in Clearance from the Terminal. For install locations and usage, see [Command-Line Tool](10-command-line-tool.md).

## Text Size

Text size isn't set in the Settings dialog. Adjust it from the **View** menu: **Zoom In** (⌘+), **Zoom Out** (⌘-), and **Actual Size** (⌘0). These apply to the rendered **View**.
